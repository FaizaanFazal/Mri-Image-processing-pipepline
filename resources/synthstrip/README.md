# SynthStrip resources

`mri_synthstrip` is the official FreeSurfer development-branch script downloaded from <https://github.com/freesurfer/freesurfer/tree/dev/mri_synthstrip>.

`synthstrip.1.pt` is the official main model downloaded from <https://ftp.nmr.mgh.harvard.edu/pub/dist/freesurfer/synthstrip/models/synthstrip.1.pt>.

- script sha256: `291c253ab2f7c0cbcb84afa769ae10909549537e727db5b92d268754b7cc7871`
- model sha256: `37417f802196186441aae3e7f385d94f8a98c64a88acaeaa2723af995c653e33`

Each dataset run also records these hashes and all preprocessing parameters in `Processed/MRI/<DATASET>/logs/preprocessing_run_config.json`.
